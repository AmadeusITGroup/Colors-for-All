What is Colors-for-all?

Colors for All turns your brand colors into an interactive contrast matrix, revealing every text-and-background combination and accessibility compliance category at once. Switch between WCAG and APCA to compare established contrast ratios with perceptual guidance tailored to font size and weight. Unlike standard pair-by-pair checkers, it helps you spot usable combinations across your entire palette in seconds. Create, name, reorder and refine colors visually or through synchronized JSON, with palettes saved locally in your browser. Less repetitive checking. Faster, better-informed color decisions.

Modes

2 modes are offered:
  • WCAG (default)
  • APCA
The APCA / WCAG selector in a palette's header switches the entire matrix. Your choice is remembered locally.

Features

You can perform the following actions for each palette :
  • Create
  • Download
  • Upload
  • Edit
  • Duplicate
  • Delete
  • Save locally
There is no limit in the number of colors for each palette. The application generates automatically a matrix (same colors horizontally and vertically) from this palette. Each cell of the matrix is the combination between 2 colors (foreground/background). The ratio (WCAG) or Lc value (APCA) is automatically computed and displayed for each combination. All accessible matches are visually highlighted. The count in the matrix's top-left cell follows the selected contrast mode; swapping foreground and background counts as a separate combination. The More options menu can download the palette as palette-name_YY-MM-DD.json or export accessible combinations in JSON, XLS, CSV, TXT, or PDF. Exports follow the active contrast mode and filters; PDF includes small previews of both colors. Use Upload file in the homepage header to import a palette, then Click Save.

Palette Editor

The palette editor has two synchronized tabs: Color picker and JSON. Valid JSON edits immediately update the visual list, and visual edits immediately update the hexadecimal JSON array. An incomplete or invalid JSON draft is preserved without replacing the last valid list; saving remains disabled until it is corrected. Each color has a rectangular preview, editable color value, drag handle, up/down controls, and a menu for duplication or deletion. Add color appends a new color at the end of the palette.
Each color can have an optional name. Edit its Name field in Color picker, or use a named JSON entry such as {"hex":"#0C66E1","name":"Primary-60"} alongside unnamed hex strings. Names follow their colors when moved, duplicated, or deleted. The matrix shows each name before its hex code, on separate lines with the same styling, in both row and column headers. Removing a name restores hex-only display.
Clicking a color's rectangular preview opens the integrated color picker in HEX format every time. RGB and HSL are available within that window. There is no additional mode or channel panel in the list. Colors are saved as opaque six-digit sRGB hex values. Transparent colors are not supported by palette storage. Cancel discards the editor's unsaved changes.

APCA rules

APCA reports a signed lightness contrast (Lc), rounded to one decimal place. Positive values mean dark text on a light background; negative values mean light text on a dark background. Rows are background colors, columns are text colors. Swapping colors can change the contrast magnitude as well as its sign.
A check marks combinations with an unrounded absolute Lc of at least 15, regardless of selected size or weight. A cross and a faded sample mark combinations below that contrast threshold. The check is not a text-readability approval. The Lc value remains displayed in the selected size and weight in either case. When the selected typography does not qualify for a text usage, the tooltip shows the minimum font size and numeric weight when a text recommendation exists. For combinations meeting the contrast threshold, a usage label is displayed below the Lc value at 13px. It is the most readable usage supported by both the unrounded absolute Lc and the selected typography, not simply the highest contrast band. Body, fluent, and large-text classifications use the Bronze guidance below. When no text usage qualifies, the label is "No text", even if Lc is above 30; the cell still receives a check and uses its text color. Absolute Lc values from 15 to below 30 always show "No text". Spot-text eligibility uses fontLookupAPCA to supply the size/weight minimum not specified in the Bronze summary; this fallback never grants a body or fluent label. Tooltip minimums refer to the lowest supported text usage, which may be spot text rather than body text. Non-text-only and unsupported entries do not pass as text. Weights 800 and 900 use the 700-weight Bronze bracket. Sizes are CSS reference pixels, based on Arial/Helvetica-like fonts with an x-height ratio around 0.52. Other typefaces can require size or weight adjustments. These reference guidelines are not a guarantee for every typeface or prolonged body-text reading. APCA recommendations are not WCAG 2 AA/AAA conformance and APCA remains a developing method.

APCA Usage Levels

Absolute LcUsageTypography and Scope
90Small body text only Preferred body-text level: at least 18px/300 or 14px/400. Extremely thin 200-weight text requires at least 24px. Non-body text can use 12px/400. Higher contrast has no ceiling for small text.
75Body text OK Body-text minimums: 24px/300, 18px/400, 16px/500, or 14px/700. Non-body text can use 15px/400. The Lc 60 size/weight combinations also qualify as body text after adding Lc 15.
60Fluent text only Readable content, not body columns or blocks: at least 48px/200, 36px/300, 24px/400, 21px/500, 18px/600, or 16px/700. Add Lc 15 to use these sizes for body text.
45Large & Sub-fluent text Headlines and large non-body text: at least 36px/400 or 24px/700. Also the minimum contrast for fine-detail pictograms and small outline icons.
30Spot & Non text only Minimum contrast for spot-readable text such as placeholders, disabled text, and copyright notices. Also for understandable solid semantic icons with a smallest solid dimension of at least 5.5px.
15No text Non-semantic non-text only, with a smallest solid dimension of at least 5px: for example, dividers or thick outlines, not fine details. This does not qualify any text combination as accessible. Treat lower contrast as invisible for many users.

Lc 90 is a suggested maximum for text larger than 36px at bold weight (700 or heavier), and for large areas of color. A tooltip warns when selected very large bold text exceeds that level; this advisory does not change the Lc or automatically fail the combination. Small fonts have no maximum. This text matrix does not evaluate icon shape, stroke thickness, solid dimensions, or whether a non-text element is semantic. Its check/cross must not be interpreted as passing those non-text requirements.
Calculations run locally using the unmodified apca-w3 0.1.9 library (algorithm 0.0.98G-4g), by Andrew Somers / Myndex. Reference: APCA Contrast Calculator. Background and documentation: Why APCA.
